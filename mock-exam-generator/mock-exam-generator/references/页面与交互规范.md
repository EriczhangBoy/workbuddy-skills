# 页面布局与交互规范（mock-exam-generator）

练习版 HTML 由 `scripts/build_exam.py` 从题库数据生成。以下为固化规范，改动需谨慎（交互 JS 与版式已充分测试）。

## 1. 页面布局（自上而下）

| 区块 | 说明 |
| --- | --- |
| 封面（section role=cover） | 单位·岗位 / 标题「{岗位}模拟题库」/ 副标题（套数·题量·答案附后）/ 难度·题型 / 结构 / 建议时长 |
| 目录（section role=body） | 编制说明、各套模拟题、参考答案（最后一页），锚点跳转 |
| 编制说明 | 题库结构总览表（综合/专业占比、涉及知识点）、难度声明、使用方法提示 |
| 各套题（section role=setN） | 每套独立分节：套标题 + 「查看本套全部答案」按钮 + 本套进度 + 综合/专业两大部分 + 模块分组 |
| 参考答案（section role=answers） | 按套分块的答案表（题号/答案/简析），最后一页 |

## 2. 交互功能清单（全部保留，勿删减）

| 功能 | 行为 |
| --- | --- |
| 单选即时判题 | 点击选项立即判定，正确项绿、错误项红，显示「回答正确/错误 + 正确答案」 |
| 多选提交判题 | 点选多个选项后点「确认本题答案」判定；漏选/错选不得分 |
| 每题「查看答案」 | 展开该题正确答案 + 简析（任意时刻可看，不影响作答） |
| 每题「清除本题」 | 清掉本题选择/判定/存储记录，不影响其他题 |
| 每套「查看本套全部答案」（复习模式） | 进入复习：本套每道题自动标绿正确答案 + 显示「正确答案：X」；按钮变「退出查看答案」，再点恢复原状（做过的恢复用户判定、没做的清空）；复习中选项不可点；跨套切换自动退出 |
| 顶栏统计 | 已答/总数/正确数/正确率 + 综合 vs 专业分项 + 各套本套进度 |
| 错题清单 | 做错的题自动汇总到该套末尾，顶栏按钮可跳转，含题号锚点 |
| 进度保存 | localStorage 自动保存（独立 key），刷新/关闭不丢失 |
| 顶栏「清除全部答案」 | 自绘确认弹窗 → 确认后全部清除、统计归零（不刷新页面） |
| 顶栏「清空进度」 | 自绘确认弹窗 → 确认后删除存储并刷新，彻底重置 |
| 手机适配 | 移动端优先：字号加大、触控区 ≥44px、顶栏 flex-wrap、按钮可点 |
| 问答题（主观题） | 每套末尾独立 `.qa-essay` 块：textarea 作答区 + 「查看参考答案」按钮展开/收起参考要点；不判分、不进统计、不进错题清单 |
| 资料分析（表格材料块） | （启用时）材料块渲染为 `.mat-block`（标题 + `.data-tbl` 表格），显示在组首道资料题上方，组内题目共用；表格数字列右对齐、移动端横向可滚动；材料块不参与判题/统计/错题清单/复习模式，仅随题目展示 |
| 打印 | @media print 隐藏全部交互元素（含问答题作答区），保留题目、材料块与答案表 |

## 3. 数据文件格式（scripts 的输入）

每套一个 md 文件，命名 `set1.md`、`set2.md`…：

```
# 第N套模拟题
## 第一部分 综合能力测试（共 25 题，限时 45 分钟）
### 一、常识判断（8 单选 + 2 多选）
**1.（单选）** 题干…
- A. 选项
- B. 选项
- C. 选项
- D. 选项
> 答案：A
> 解析：…
### 二、言语理解与表达（4 题）
…
## 第二部分 专业能力测试（共 25 题，限时 45 分钟）
### 一、水力学基础（3 题）
…
### 八、专业问答题（3 题，结合岗位情景作答）
**51.（问答）** 情景：…请说明排查思路/处理步骤。
> 参考要点：1.…；2.…；3.…；4.…
**52.（问答）** …
> 参考要点：…
## 第一部分 综合能力测试（启用资料分析后追加题量）
### 六、资料分析（2 组材料，每组 4~5 题，结合表格材料作答）
**（材料）** 某省 2019—2025 年粮食产量及增速如下表：
| 年份 | 粮食产量（万吨） | 同比增长率 |
| --- | --- | --- |
| 2019 | 6120 | — |
| 2020 | 6270 | 2.5% |
| … | … | … |
**26.（单选）** 2025 年该省粮食产量较 2019 年增长约（ ）。
- A. 12.6%
- B. 14.7%
- C. 16.3%
- D. 18.2%
> 答案：B
> 解析：(7020−6120)÷6120 ≈ 14.7%
**27.（多选）** 下列表述正确的有（ ）。
- A. …
- B. …
- C. …
- D. …
> 答案：AC
> 解析：…
**28.（单选）** …
> 答案：C
> 解析：…
**（材料）** 某市 2025 年各月社会消费品零售总额…
**29.（单选）** …
> 答案：A
> 解析：…
…
```

- `##` 为部分标题（含"专业"二字归入专业区，否则归综合区，用于分块统计）
- `###` 为模块标题（渲染为 h4 分组）
- 题号每套内从 1 开始，**客观题 1..per_set、问答题接续编号**，生成时自动加全局偏移（避免跨套冲突；每套偏移 = 套序 × (per_set + essay)）
- 客观题：选项字母 A-E；`> 答案：` 与 `> 解析：` 每题必填
- 问答题：类型标注 `（问答）`，无选项，必须附 `> 参考要点：`（渲染为"查看参考答案"展开内容）
- **资料分析（可选模块）**：
  - 材料块：`**（材料）** 标题` 独占一行，下方紧跟 markdown 表格（表头行 + `---` 分隔行 + 6~8 行数据），表格后直接接题目，期间不能插入其他内容；
  - 组内题目使用**普通 `（单选）`/`（多选）` 标记**（判题复用现有交互，无独立题型标记）；
  - **默认每套 2 组材料，每组 4~5 道题**，组内题号连续；材料块由生成器渲染一次（组首题上方），同组后续题不再重复材料；

## 4. 技术约束

- 单文件 HTML，无外部依赖，双击即用；答案数据运行时从答案表 DOM 读取（单一数据源，勿在 JS 里硬编码答案）。
- localStorage key 必须以 `gps_qa_` 前缀开头且**每个题库唯一**（build_exam.py 的 `--store-key` 参数，建议 `gps_qa_{岗位英文slug}`），避免不同题库互相污染。
- 生成产物命名：`{岗位}模拟题库-练习版.html`。
- 交互 JS（`assets/qa-interact.js`）与版式 head（`assets/base-head.html`）为已测试模板，**不要重写**；如需扩展功能，在模板上增量修改并跑 `scripts/test_exam.js` 回归。
- **问答题渲染为独立 `.qa-essay` 块**：内含 textarea 作答区 + 「查看参考答案」按钮 + 隐藏的 `.essay-ref` 参考要点；不参与判题/正确率统计/错题清单/复习模式，仅按钮展开收起要点（交互已在 `qa-interact.js` 内置）。
- **资料分析渲染**：`build_exam.py` 将 markdown 表格转换为 `<table class="data-tbl">`（外层 `.tbl-wrap` 支持移动端横向滚动），置于 `.mat-block` 材料块内；材料块插在组首道题（引用该材料的单选/多选题）的 `.question` 内部最上方，同组后续题不带材料块；组内题目为普通单选/多选，判题交互复用现有逻辑，无独立题型标记。

## 5. 交付前必做

1. `check_bank.py` 题库自检通过（含 `--essay`）
2. `build_exam.py` 生成 HTML（含 `--essay`）
3. `test_exam.js` 自动测试全部通过（含 essay 参数；≥ 30 项断言）
4. 移动端视口（如 390px 宽）截图确认布局正常（封面/目录/客观题/问答题各看一次）
