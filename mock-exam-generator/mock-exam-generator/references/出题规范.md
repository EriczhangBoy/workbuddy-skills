# 出题规范（mock-exam-generator）

题库按「综合能力测试 50% + 专业能力测试 50%」结构编制。以下规范为硬性要求。

## 1. 综合能力测试（默认每套 25 题）

**目的**：考查通用素质，**严禁涉及岗位专业知识**（专业题全部放到专业能力测试部分）。

**题型结构**（单选 20 + 多选 5，可微调）：

| 模块 | 题量 | 取材范围 | 难度 |
| --- | --- | --- | --- |
| 常识判断 | 8 单选 + 2 多选 | 时政（近两年全会/政府工作报告/重大战略）、历史（朝代/事件/人物）、地理（中国地形/河流/行政区划/世界地理）、文化（四大名著/唐诗宋词/传统节日/成语典故/文物建筑）、科技（基础物理化学生物/天文/航天）、法律（宪法/民法典/劳动法/安全生产法）、经济（GDP/CPI/通货膨胀/货币政策）、生活（节气/健康/用电安全） | 中等偏易 |
| 言语理解 | 4 单选 | 选词填空、病句辨析、语句排序、主旨概括/标题拟定 | 中等 |
| 数量关系 | 3 单选 + 1 多选 | 比例、工程合作、行程、年龄、利润、简单计算（不超过初高中水平） | 中等偏易 |
| 判断推理 | 4 单选 + 1 多选 | 类比推理（如"医生：患者"）、定义判断、逻辑三段论、充分/必要条件推理、演绎/归纳辨析 | 中等 |
| 策略选择 | 1 单选 + 1 多选 | 职场通用情境：汇报、沟通、批评、协作、任务优先级、突发事件（不依赖岗位专业） | 偏易 |

**微调入口**：调用时用户可指定「综合测试涉及方向」（如"多经济金融常识""多法律常识"），据此调整常识判断取材比重，结构不变。

**可选模块——资料分析（表格数据分析题，默认不加）**：用户明确要求增加时，在综合区末尾追加「资料分析」模块（详见 §2.6），默认每套 **2 组**材料、每组 **4~5 道**题，综合客观题量相应追加。

## 2. 专业能力测试（默认每套 25 题）

- 按岗位核心专业领域划分模块（如给排水岗：水力学/给水工程/给水处理/排水工程/污水处理/污泥处理/水质检测/泵与自控/安全法规），每模块 1~4 题。
- 取材岗位职责说明书 + 该专业主干知识；难度按用户指定（简单/中等/困难）。
- 涉及标准/规范的题以现行有效版本为准（如 GB 5749、GB 18918、GB 50013、GB 50268 等），数值必须准确。

## 2.5 问答题（默认每套 3 道，主观题）

- **位置**：放在专业能力测试之后，独立模块（如"八、专业问答题（3 题）"），编号接续客观题（如客观题 1-50，问答题 51-53）。
- **题型**：岗位专业**情景题**为主（如"某泵启动后流量偏小如何排查""突发停电如何应急处置"），每套覆盖不同方向（设备故障排查 / 应急处置 / 安全作业 / 管理方法），贴近真实考试与岗位高频场景。
- **要求**：题干描述具体情景 + 明确作答要求；必须附 `> 参考要点：`（3~5 个要点，含关键步骤与专业术语），供自评。
- **不判分**：问答题为开放式作答，交互层只提供"查看参考答案"展开要点，不计入正确率统计。
- 用户明确"不要问答题"时才可省略；否则默认按每套 3 道编制。

## 2.6 资料分析（表格数据分析题，可选，默认不加）

> 触发方式：**仅当用户明确要求"加表格数据分析题/资料分析题"时才编制**（生成前必须询问确认，见 SKILL.md 第 0 步）。默认不出现，与问答题（默认加）相反。

- **位置**：综合能力测试末尾，独立模块（如"六、资料分析（2 组材料，每组 4~5 题，结合表格材料作答）"），编号接续综合区客观题。
- **结构**：**默认每套 2 组**材料，每组 = 1 张统计表格（材料块）+ **4~5 道题**（单选与多选混合均可），组内题号连续；用户可要求更多/更少组。
- **材料要求**：
  - 表格 6~8 行数据 + 表头，列数 ≤4（表头 + 2~3 个数据列），数据自洽、可实际演算验证；
  - 主题取**通用统计场景**（企业销售、城市经济、居民消费、能源、交通、人口等），**严禁岗位专业数据与专业词**（综合区纯净原则）；
  - 材料块格式：`**（材料）** 标题` 独占一行，下方紧跟 markdown 表格（`| 分隔`），表格后接题目，见 `页面与交互规范.md` §3。
- **考法覆盖**：每组 4~5 题须覆盖**不同考法**，常见：增长率/增长量、比重、倍数、平均数、增速比较、合计/差值、基期量、综合分析（选出正确/错误的一项）。避免同一组内两道题同类。
- **题型**：单选与多选均可混合（多选答案 ≥2、干扰项明确错误）；判题复用现有单选/多选交互，无需新题型标记。
- **难度**：与行测/职测资料分析相当（中等）：两步以内计算，干扰项为"看错列/用错基期/漏合计"类易错项。
- **硬性要求**：每题计算必须实际演算（数字不能凭感觉）；答案唯一；正确项落点遵循 §5.5（资料题也计入整卷落点序列，避免连续同字母）。

## 3. 难度分级指引

| 难度 | 综合区 | 专业区 |
| --- | --- | --- |
| 简单 | 常识为主、计算为一步运算、干扰项明显 | 概念记忆题为主，计算简单 |
| 中等（默认） | 常识+基础逻辑，计算两步以内 | 概念+简单应用，规范数值对照 |
| 困难 | 常识细节、推理链条更长、多步计算 | 需要综合判断/多条件计算/规范深挖 |

## 4. 答案唯一性与正确性（硬性要求）

1. **单选题必须答案唯一**：只有一个选项正确，其余选项必须是明确的错误项（避免"都对""都错"）。
2. **多选题**：答案至少 2 项；干扰项必须是明确错误表述；题干注明"多选"。
3. 每一题的**答案字母必须存在于该题选项中**（自检会自动校验）。
4. 数字计算题必须实际演算验证，不能凭感觉；规范数值必须核对现行标准。
5. **综合区不得出现岗位专业词**（如给排水岗的：给水、污水、水厂、滤池、污泥、曝气、管网、BOD、COD 等）。调用时会生成禁用词表并自动校验。
6. 常识判断题须基于公认事实（时政题基于已公开的官方表述，避免有争议的细节）。

## 5. 多选题设计原则

- 选项 4~5 个（A-E），正确答案 2~4 个。
- 干扰项与正确项同主题、同风格，不能一眼排除。
- 全选正确（ABCDE）的题每套不超过 1 道，避免无脑全选。

## 5.5 正确答案落点控制（硬性要求，从出题源头避免规律）

**根因**：AI 出题时"先确定正确答案、再写选项"，正确表述自然落在第一个选项（A），导致 A 占比可达 70%+。这是出题流程的系统性偏差——**事后脚本随机/轮转都只是补救，且轮转会形成 A,B,C,D 周期规律，同样可预测**。正确做法是**出题时就控制正确项落点**：

- **写选项前先定落点**：每道题在写选项之前，先决定正确项放哪个字母位置（刻意打散，不用 ABCD 轮转、不固定 A），再写正确表述与干扰项。
- **先写干扰项，再插入正确项**：先列出 3~4 个干扰项，把正确项"插"到非首位的指定位置，从机制上杜绝正确项恒居 A。
- **整卷落点规划**：出题前先给整卷单选规划一个落点序列（各字母约占 1/4，顺序打散、无周期、避免连续 3 个相同答案），按序列逐题落位。
- **编完自检**：按题号列出答案字母序列，人工扫描三类问题：①某字母占比 >40%；②出现 ABCD 周期（A,B,C,D,A…）；③连续 3 个以上相同。发现问题**手工调整**对应题的选项行顺序（只移动正确项位置，不改题干与正确内容）。

## 6. 出题复核 Checklist（第 1.5 步，逐题执行）

生成题库数据后、跑脚本自检前，**必须逐题复核**以下各项；发现问题立即修正并重核，直到全部通过。

| # | 复核项 | 说明 |
| --- | --- | --- |
| 1 | 单选答案唯一 | 逐一确认每个干扰项确实是错误表述；不存在"也对但有争议""题干条件不足"的选项（最高频翻车点） |
| 2 | 计算题重算 | 数量关系与专业计算题重新演算，确认选项数值正确、无单位错误 |
| 3 | 规范数值核对 | GB/行标限值、单位、标准编号对照现行有效版本，禁止凭印象 |
| 4 | 常识/时政事实 | 基于公认事实与官方公开表述；不确定的事实不出题或改题 |
| 5 | 多选题答案 ≥2 | 干扰项为明确错误；整题不会出现"全选都对"歧义 |
| 6 | 综合区纯净 | 综合区题干+选项不含任何岗位专业词 |
| 7 | 解析自洽 | 每题解析能推导出所给答案，解析与答案一致 |
| 8 | 答案落点不规律 | 按题号列出答案字母序列人工扫描：任一字母占比 ≤40%、无 ABCD 周期轮转、无连续 3 个以上相同；不达标则手工调整对应题选项顺序（不改题干与正确内容） |
| 9 | 问答题 | 每套 3 道专业情景题，均含 3~5 点参考要点；不涉及岗位专业词禁区之外的其他要求 |
| 10 | 资料分析 | （启用时）每组材料表格 6~8 行、数据自洽可演算；每组 4~5 道题、组内考法不重复；每道资料题计算重算、单选答案唯一/多选 ≥2；材料与题目均无岗位专业词；材料块格式正确（`**（材料）**` 标题 + markdown 表格） |

> 提醒：`check_bank.py` 只校验结构与格式（题量、答案字母在选项内、单选答案长度=1、综合区无禁用词、问答题含参考要点），**校验通过不代表知识点正确**。知识点正确性由本 Checklist 的人工（AI）复核把关。
