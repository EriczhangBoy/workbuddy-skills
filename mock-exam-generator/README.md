# mock-exam-generator（模拟题库生成器）

WorkBuddy 技能：为**任意岗位**生成「综合能力测试 50% + 专业能力测试 50%」的交互式模拟题库练习版 HTML（单文件、手机友好、进度自动保存）。

## 安装

```bash
unzip mock-exam-generator.zip -d ~/.workbuddy/skills/
```

解压后应得到 `~/.workbuddy/skills/mock-exam-generator/SKILL.md`。

## 用法（触发词：模拟题 / 题库 / 练习题 / 模拟试卷）

新开会话后直接说，例如：

> 给「给排水技术岗」生成模拟题：岗位职责是自来水/污水厂工艺管理…，专业方向给排水科学与工程，综合测试按事业单位职测偏向出题，难度中等，3 套，每套综合 25 + 专业 25。

技能会自动执行：

1. **收集参数**：岗位名称、职责/要求、专业知识类型、综合测试涉及方向、整体难度、套数、每套题量、是否含解析（必填项用询问确认，可选项一次性合并确认，用户明确"按默认"时跳过询问）；
2. **编制题库**：综合能力（常识/言语/数量/判断/策略，不涉及岗位专业）+ 专业能力（按岗位知识）+ 问答题（默认每套 3 道情景题）；
3. **AI 逐题复核**（知识点正确性）：单选答案唯一、计算重算、规范数值核对、综合区无专业词、正确项落点均衡；
4. **脚本自检 + 自动测试**：结构校验 + 交互断言全部通过才交付；
5. **生成并交付**：练习版 HTML 自动落库 `~/Documents/WorkBuddy-Outputs/模拟题库/{日期}-{岗位名}/`。

## 产出页面功能

| 功能 | 说明 |
| --- | --- |
| 单选即时判题 | 点选项立即判定，对绿错红 |
| 多选提交判题 | 选完点「确认本题答案」；漏选/错选不得分 |
| 问答题 | 每套末尾独立作答区（textarea）+「查看参考答案」展开参考要点；不判分、不进统计与错题清单 |
| 每题「查看答案」「清除本题」 | 随时看解析；单独重做本题 |
| 每套「查看本套全部答案」 | 进入复习模式：题目上自动高亮正确答案，退出恢复原状（不污染答题记录） |
| 顶栏统计 | 已答/正确率 + 综合 vs 专业分项 + 各套进度 |
| 错题清单 | 自动汇总到套末，可跳转原题 |
| 进度保存 | localStorage 自动保存（每题库独立 key），刷新不丢失 |
| 重置 | 「清除全部答案」（不刷新）+「清空进度」（删存储刷新），页面内确认弹窗 |
| 手机适配 | 移动端优先布局，触控友好 |

## 内置文件

| 文件 | 用途 |
| --- | --- |
| `SKILL.md` | 主流程与硬性规则 |
| `scripts/check_bank.py` | 题库结构自检（题量/答案/专业词隔离/问答题型） |
| `scripts/build_exam.py` | 生成练习版 HTML（支持单选/多选/问答） |
| `scripts/test_exam.js` | jsdom 自动测试 |
| `assets/qa-interact.js` | 交互层模板（判题/复习/统计/错题/问答/重置/弹窗） |
| `assets/base-head.html` | 页面版式模板（含全部样式） |
| `references/出题规范.md` | 出题结构、取材、难度、问答规范、复核 Checklist |
| `references/页面与交互规范.md` | 布局、交互清单、数据格式、技术约束 |

## 变更记录

- **v1.2（2026-08-27）**
  - 新增**资料分析（表格数据分析题）**：默认不加（0 组），生成前用 `AskUserQuestion` 询问用户是否增加，确定后**默认每套 2 组**表格材料、**每组 4~5 道题（单选或多选均可）**，放综合区末尾，类似行测"资料分析"；
  - 题库格式新增材料块：`**（材料）** 标题` + markdown 表格；组内题目用普通 `（单选）`/`（多选）` 标记，判题复用现有交互（无独立题型标记）；
  - `build_exam.py` 支持 markdown 表格 → `.data-tbl` 表格渲染（`.mat-block` 材料块、组首题显示、横向滚动、数字右对齐），新增 `--data-groups` / `--data-per-group` 参数；
  - `check_bank.py` 校验材料组数、每组 4~5 题、材料表格、专业词（材料文本纳入综合区检查），新增 `--data-groups` / `--data-per-group` 参数；
  - `test_exam.js` 新增材料块断言（组数、组首题、表格存在），新增 data-groups / data-per-group 参数；
  - 出题规范 §2.6 与复核 Checklist、页面交互规范 §3 同步更新。
- **v1.1（2026-08-27）**
  - 参数收集改为 `AskUserQuestion` 一次性合并确认：必填项（岗位名称/专业类型）缺失必问，可选项合并确认；用户明确"按默认/直接生成"时跳过询问并在回复中列出所取默认值；
  - 新增**问答题（主观题）**全链路支持：出题规范 §2.5（每套默认 3 道情景题、附参考要点、不判分）、页面规范、build_exam / check_bank / qa-interact 均支持「问答」题型；
  - 新增**正确答案落点控制**硬性要求（出题规范 §5.5）：从出题源头控制正确项分布，避免 A 占比过高与轮转规律；
  - 页面标题不再硬编码岗位名，改用 `document.title`（去除岗位残留）。
- **v1.0（2026-08-22）**：初始可复用版本（含 AI 复核步骤、产出物落库约定）。
